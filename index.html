Home Assistant

A private home automation installation for a single household.

What this is

This page identifies a personal Home Assistant installation that runs on a computer inside one private home. It is not a public product or service, and it has no users other than the household that owns it.

What it does with Google

The installation connects to the owner's own Google account so that it can:

  • Google Drive: upload encrypted backups of the home automation system to a folder named "Home Assistant" in the owner's Drive.
  • Google Sheets (optional): append rows of home energy and temperature readings to a spreadsheet the installation creates in the owner's Drive.

It can only access the files it creates itself. It cannot read or change any other files in the account.

Privacy policy

Home Assistant is open-source software from the Open Home Foundation. This page describes one private installation and is not affiliated with or endorsed by Home Assistant, the Open Home Foundation or Google.
